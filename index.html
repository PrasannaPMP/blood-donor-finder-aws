13 AWS Services Used

Patient Blood Group Compatibility

Select the recipient's blood group. The engine automatically filters donors based on medical compatibility rules and 90-day cooldown status.

Active Hospital Emergencies

Live feed of emergency requirements. Donors with compatible blood groups receive direct emails via Amazon SNS.

Dispatch Urgent Blood Requirement

Submitting this form commits the record to DynamoDB. The DynamoDB Stream immediately triggers an AWS Lambda function which dispatches fan-out alerts via Amazon SNS.

Donor Registration & Alert Enrollment

Register as a certified donor. Your email is attached to Amazon SNS with automated filter policies so you only get pinged for compatible emergencies.

Cloud Architecture & Viva Presentation Reference

How the 13 AWS services work together in this course project:

1
CloudFront + ALB

Global edge caching + Multi-AZ Application Load Balancer across 2 subnets.

2
Auto Scaling EC2

1–3 Amazon Linux 2023 instances scaling at 50% CPU threshold.

3
DynamoDB

On-demand tables with 7-day TTL auto-cleanup and encrypted storage.

4
DynamoDB Streams

Captures new blood requests in real-time without polling.

5
AWS Lambda

Calculates compatibility matrix & publishes a single filtered message.

6
Amazon SNS

Filter policy delivers instant email alerts matching donor blood groups.

7
AWS WAF

Blocks fake-request spam (max 10 per IP / 5 min), bot floods and SQL injection at the load balancer.
